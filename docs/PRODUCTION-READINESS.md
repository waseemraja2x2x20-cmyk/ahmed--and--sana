# Production readiness

The repository currently contains reference artwork, asset sheets, builder
scripts, and directory scaffolding. It does not yet contain production-ready
layered PSDs, painted reusable animation assets, or verified Character Animator
rigs.

## 1. Layered source and puppet artwork

- [ ] Create true layered `characters/boy/BOY.psd` and
      `characters/girl/GIRL.psd`.
- [ ] Paint and reconstruct hidden areas rather than placing cropped PNGs:
      hair behind the body, jacket behind the shirt, and skin behind raised
      arms.
- [ ] Populate the groups generated by the Photoshop builders.
- [ ] Save production puppets as `puppets/Ahmed/Ahmed.psd` and
      `puppets/Sana/Sana.psd`.
- [ ] Export `Ahmed.png` and `Sana.png` previews after approval.

## 2. Reusable animation assets

The supplied sheets are references, not finished production layers.

- [ ] Paint the 12 mouth visemes in the character style under `assets/mouths/`.
- [ ] Create eye whites, highlighted pupils, and independent blink lids under
      `assets/eyes/`, including open, half-closed, and closed states.
- [ ] Create neutral, angry, surprised, and sad eyebrow states under
      `assets/eyebrows/`.
- [ ] Create five hand poses per hand under `assets/hands/`: normal,
      face-support, point, wave, and hold-object.
- [ ] Keep line weight, colors, proportions, and transparent edges consistent
      with the canonical references.

## 3. Rigging and tests

Adobe Character Animator validation is still required:

- [ ] Face tracking with frontal/head/chest/waist tags.
- [ ] Independent left and right blinking.
- [ ] Mapping for all 12 visemes.
- [ ] Head turns, if a three-quarter view is produced.
- [ ] Shoulder, elbow, wrist, and draggable hand controls.
- [ ] Hip, knee, ankle, and walking behavior.
- [ ] Stretch tests with no gaps, broken joints, or identity drift.

## 4. Animation content

- [ ] Build cafe, street, rain, and rooftop backgrounds and props.
- [ ] Add coffee cups, umbrella, and book hold-object setups.
- [ ] Create eight-frame Ahmed and Sana walk cycles.
- [ ] Create reusable gestures and expression triggers.
- [ ] Add episode scripts and dialogue timing.
- [ ] Add dialogue test lines, music, rain, footsteps, and other SFX.

## 5. Final quality control

- [ ] Raise arms to maximum and check armpits for holes.
- [ ] Bend elbows 90 degrees and check volume preservation.
- [ ] Move the head and confirm eye and facial alignment.
- [ ] Turn Sana and confirm back hair remains behind the top/body.
- [ ] Confirm cups, umbrellas, and books are correctly gripped.
- [ ] Compare standing, talking, walking, turning, gesturing, and emotional
      poses against the canonical reference.

## Current blockers

The repository cannot generate these deliverables from the existing flat
references alone. Layer painting, hidden-area reconstruction, PSD authoring,
and Character Animator testing require an artist and the target desktop
applications. Do not mark these items complete until the resulting files have
been reviewed against the canonical artwork.
