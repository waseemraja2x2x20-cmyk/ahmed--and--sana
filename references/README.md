# References

Store character sheets, poses, color palettes, and other visual references in
this directory. Use descriptive filenames and keep the canonical character
sheet at `character-sheet.png`.

`character-sheet.png` currently contains the shared Ahmed and Sana reference.
Per-character crops may be added later as `ahmed-reference.png` and
`sana-reference.png`; until then, use the shared sheet when approving assets.
