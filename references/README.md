# Character References

This directory contains the canonical visual references for Ahmed and Sana.

## Files

```text
character-sheet.png
ahmed-reference.png
sana-reference.png
```

## Canonical Status

The Ahmed and Sana reference artwork is authoritative.

All production assets must visually conform to these references.

The references define:

- Face
- Hair
- Eyes
- Eyebrows
- Mouth
- Body
- Clothing
- Proportions
- Silhouette
- Illustration style

## Priority

When visual inconsistencies occur:

```text
Canonical Reference
        ↓
Production Puppet
        ↓
Animation Asset
        ↓
Temporary Scene Asset
```

The higher-level reference always has priority.

## Do Not

Do not:

- Redesign the character
- Change facial proportions
- Change clothing
- Change hairstyle
- Change the illustration style
- Replace the character with an AI-generated alternative

unless explicitly requested.

## Usage

These references should be consulted whenever creating:

- New poses
- New expressions
- New body parts
- New hand positions
- New mouth shapes
- New scenes
- New props interacting with Ahmed or Sana
- New animation assets

`character-sheet.png` currently contains the shared Ahmed and Sana reference.
Add `ahmed-reference.png` and `sana-reference.png` when approved
per-character crops become available.
